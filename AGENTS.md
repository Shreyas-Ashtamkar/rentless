# Agent Guidance

## Repository status

This repository is intentionally minimal. It currently contains a short `README.md`, a
`.gitignore`, and the project license. There is no application code or configured
build, lint, or test system yet.

## Working rules

1. Read the relevant existing files before editing.
2. Make the smallest focused change that satisfies the request.
3. Avoid introducing frameworks, dependencies, or tooling without a concrete need.
4. Add or update documentation when a change affects how users work with the repository.
5. Run only validation commands that are defined by the repository; report when none exist.
6. Review the diff for unintended changes and accidentally included secrets before committing.
